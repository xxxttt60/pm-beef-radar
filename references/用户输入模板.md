# 用户输入模板（PM 产品版）

用户需要模板、示例，或推荐模式缺失需要反问时加载本文件。

## 反问话术（模式缺失时固定使用）

```text
你想按哪种推荐模式执行？

- ai-product-only：只找通用场景的 AI Agent 产品（知识库问答、学习、面试、写作/办公 Agent）
- b2b-only：只找 B 端场景的 Agent 产品（智能客服、销售、招聘、数据分析 Agent）
- mixed：一个通用场景 Agent + 一个 B 端场景 Agent
- safe-mode：只推荐容易跑通、7 天能出拆解和 PRD 的 Agent 产品
- vertical-mode：优先贴合你的目标垂直行业场景的 Agent 产品

你回复其中一个模式后，我再开始搜索 GitHub 并生成简历叙事。
```

## 完整输入模板

```text
牛肉雷达产品版，推荐模式 {ai-product-only | b2b-only | mixed | safe-mode | vertical-mode}
目标岗位：如 AI 产品经理（智能客服方向）/ B 端产品经理
垂直行业：按用户实际填写（如电商、金融、医疗、教育、制造等，可留空）
体验能力：能否跑 Docker / 调 API / 读代码，模型 API 预算
时间预算：如 1 周 / 2 周 / 1 个月
项目偏好：想要的产品类型与叙事方向
避开方向：如纯框架、chatgpt 套壳、IoT、需要 GPU 的项目
输出需求：产品拆解 / PRD 大纲 / 0-1 改造路线 / 简历写法 / 面试问答（可多选，默认全要）
```

## AI 产品经理场景的额外要求

目标岗位是 AI 产品经理时，候选项目必须通过 Agent 四件套校验（多轮上下文 / RAG / 工具调用 / 记忆，至少命中 2 项）。只有「AI 客服台 / 知识库问答界面」而无多轮与工具能力的项目会被淘汰；传统客服台、工单、BI 等宿主平台只能作为落地背景，不能作为 Agent 项目主体。

## 场景示例

### 快速找 AI 产品

```text
牛肉雷达产品版，推荐模式 ai-product-only，我想找一个能包装成智能客服或知识库助手的 AI Agent 项目，本地有 Docker。
```

### 垂直行业叙事

```text
牛肉雷达产品版，推荐模式 vertical-mode，我在零售行业做了三年数据分析产品，想找一个数据问数 / ChatBI 方向的开源项目，包装成"零售经营智能问数助手"。
```

### 求稳快出

```text
牛肉雷达产品版，推荐模式 safe-mode，一周时间，要一个 Docker 一键能跑、文档清楚的项目，先产出一份产品拆解和 PRD。
```
